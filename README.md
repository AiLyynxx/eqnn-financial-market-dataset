# Financial Market Classification Dataset

Companion dataset for **Evolutionary Quantum Neural Networks for Financial Market Classification**, by Giovanni Acampora, Angela Chiatto, Cuono Massimo Coletta, Domenico Messina, Giovanni Paragliola and Autilia Vitiello. Accepted at the 2026 IEEE 2nd International Conference on Quantum Artificial Intelligence (QAI); publication and the paper DOI are pending.

The dataset is provided by AILYNX S.R.L. for research use. It supports comparisons of classical and quantum classifiers on per-asset bullish/bearish labels generated by an offline reference system.

## Contents

Both Parquet files contain 50 input features, six metadata columns and a `Date` datetime index. They cover 488 stocks and 20 sectors from the S&P 500 research universe.

| File | Rows | Observed dates, inclusive | Partitions |
|---|---:|---|---|
| `dataset.parquet` | 10,000 | 2019-01-08 to 2024-06-14 | train 6,042; validation 1,951; test 2,007 |
| `evaluation_set.parquet` | 321,540 | 2023-06-15 to 2026-01-30 | test 122,925; extended 198,615 |

The curated artifact uses `quality >= 0.6`, sector quotas proportional to the number of stocks, approximately balanced classes within each sector, and random sampling without replacement with seed 42. Its 10,000 observations include training, validation and curated test data.

The evaluation artifact has no quality filter, class balancing or subsampling. Its test period overlaps the curated test period; these are not independent datasets. Its first five observations per stock after the evaluation boundary were removed for rolling-quality warm-up, explaining its observed start on June 15 rather than June 8.

The predefined chronological boundaries are:

- Training: dates before 2022-06-06.
- Validation: 2022-06-06 inclusive to 2023-06-08 exclusive.
- Test: 2023-06-08 inclusive to 2024-06-17 exclusive.
- Extended evaluation: from 2024-06-17 through the last available date, 2026-01-30.

Preserve the supplied splits when comparing results. Fit any additional preprocessing and select model settings using training/validation only. Report evaluation on `test`, `extended` and their union separately.

## Schema

| Column | Meaning | Model input? |
|---|---|---|
| `Date` (index) | Observation date | No |
| `Ticker` | Instrument identifier | No |
| `sector` | FactSet Economic Sector | No |
| `Signal` | Continuous reference score | No |
| `label_bin` | Target: `Signal > 0.5611`; 1 bullish, 0 bearish | Target only |
| `quality` | Selection and analysis score derived from the reference signal | No |
| `split` | Predefined partition | No |
| Remaining 50 columns | 30 expert confidence features (`4` through `33`) and 20 preprocessed technical indicators | Yes |

Use the ordered `feature_names` list in `dataset_metadata.json`. **Do not include `Signal`, `label_bin` or `quality` in the feature matrix.**

## Load the dataset

Requires pandas and a Parquet reader such as PyArrow.

```python
import json
from pathlib import Path
import pandas as pd

data = Path("data")
metadata = json.loads((data / "dataset_metadata.json").read_text())
features = metadata["feature_names"]
curated = pd.read_parquet(data / "dataset.parquet")
evaluation = pd.read_parquet(data / "evaluation_set.parquet")

assert len(features) == 50
assert not {"Signal", "label_bin", "quality", "split", "Ticker", "sector"}.intersection(features)
assert curated["split"].value_counts().to_dict() == {"train": 6042, "val": 1951, "test": 2007}
assert evaluation["split"].value_counts().to_dict() == {"test": 122925, "extended": 198615}

train = curated[curated["split"] == "train"]
validation = curated[curated["split"] == "val"]
curated_test = curated[curated["split"] == "test"]

X_train, y_train = train[features], train["label_bin"]
X_validation, y_validation = validation[features], validation["label_bin"]
X_test, y_test = curated_test[features], curated_test["label_bin"]
X_evaluation, y_evaluation = evaluation[features], evaluation["label_bin"]
```

## Construction and interpretation

The upstream OHLCV data came from FactSet and were transformed by the proprietary reference pipeline. Raw OHLCV data, the upstream archive, and model weights are not included.

The paper describes a 14-market-day lookahead in the offline labeling procedure. This benchmark measures reproduction of the reference labels from the supplied features; labels and quality scores must not be interpreted as information available in real time.

For reference score `s` and threshold `tau = 0.5611`, the distance is `(tau - s) / tau` when `s <= tau`, otherwise `(s - tau) / (1 - tau)`. Quality subtracts `0.5 * min(1, std_past / 0.5)` from that distance, where `std_past` is the sample standard deviation over the five preceding observations of the same stock. The trailing quality calculation does not remove lookahead from the underlying reference labels.

The curated quality filter selects easier observations. Performance on the curated test subset should therefore be accompanied by results on the unfiltered evaluation set. The supplied artifacts preserve the exact rows and splits used by the research group; they have not been regenerated for this release.
